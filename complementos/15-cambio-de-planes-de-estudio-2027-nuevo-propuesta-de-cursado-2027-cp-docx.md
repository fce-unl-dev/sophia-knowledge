# PROPUESTA DE CURSADO 2027 PARA CP

Este documento presenta la propuesta de cursado para la carrera de Contador Público (CP) para el año 2027, incluyendo la distribución de asignaturas por cuatrimestre y año.

---

## Contenido

### Plan de Estudios y Carga Horaria

| Asignaturas del nuevo Plan de Estudios        | Propuestas 2027 |
| :--- | :--- |
| Fundamentos de Contabilidad                   | Dictado exclusivo para plan 2027. |
| Administración General                        | Dictado exclusivo para plan 2027 |
| Matemática Básica                             | Dictado exclusivo para ingresantes 2027- Evaluación: promoción |
| Economía Básica                               | Propuesta para plan 2019 |
| Sistemas Contables                            | Propuesta para plan 2019 |
| Administración Aplicada                       | Administración IV ofrece un complemento. Administración II y IV ofrecen una propuesta integral para aquellos estudiantes de plan 2019 que no tienen ninguna de las dos aprobadas.                                  |
| Instituciones del Derecho                     | Instituciones de Derecho II ofrece complemento. Ambos derechos ofrecerán una propuesta integral para quienes no tengan ninguna aprobada.                                                                        |
| Matemática Aplicada                           | Propuestas para el plan 2019. Se modifica la correlativa de MCL-Cálculo. |
| Economía Aplicada                             | Microeconomia y Macroeconomia dan complementos y ensayan propuesta del nuevo Plan para quienes no tengan ninguna de las materias.                                                                               |
| Administración y Finanzas Públicas            | Propuestas complementarias tanto para Finanzas Públicas como para Administración Pública. Ensayo de nueva materia para estudiantes de plan 2019 que no tienen ninguna de las dos aprobadas.                        |
| Taller de Práctica Integradora I              | Propuesta para plan 2019. Se analizará la posibilidad de levantar algunas correlatividades en el segundo cuatrimestre. |
| Informes Contables                            | Propuesta integral de Informes Contables (Contabilidad IV y Contabilidad V) para quienes no tengan ninguna de las asignaturas y dictado de complemento para Contabilidad V.                                       |
| Tecnologías de la Información                 | Informática para plan 2019 adaptada a la nueva asignatura |
| Contabilidad de Gestión y Costos              | Costos II dicta complemento "en vistas al nuevo plan". Costos I propone exámenes para quienes la tengan pendiente. |
| Teoría y Técnica Impositiva I (Consumo)       | Levantar la correlatividad hasta el 2030 de la actual T y Técnica I (Ganancias) para realizar Técnica II (Consumo). |
| Auditoría                                     | Cuatrimestral. Se levanta la correlatividad de Taller II y de TyT I (Ganancias). Promoción por parciales: 1er parcial en el turno de mayo y octubre, recuperatorio del 2do parcial en el primer turno de junio y noviembre. |
| Teoría y Técnica Impositiva II (Ganancias)    | Se cuatrimestraliza el cursado a partir de 2027. |
| Taller de Práctica Integradora II             | Se analizará levantar correlatividades para el segundo cuatrimestre: Administración II y Macroeconomía |
